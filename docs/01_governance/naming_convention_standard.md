# Naming Convention Standard

Document ID: ontological_framework_naming_convention_v1

## 1. Primitive Naming

- lowercase-hyphenated for primitives
- ART-### for artifacts
- domain:primitive for cross-references

## 2. Document Naming

- YYYY-MM-DD-{descriptive-slug}.md for experiments
- {protocol-name}-v{N}.md for protocols
- category_descriptive_name.md for docs
