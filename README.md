# scale-threshold-emergence

Research framework for studying threshold transitions across scales — from chemistry to life to mind to society to reflexive knowledge systems.

## Overview

This repository preserves and structures the "Theory of Everything" research thread, organizing knowledge around:

- **Threshold transitions**: Critical emergence points between domains (TP-05 through TP-09)
- **Research lanes**: Structured inquiry into origin questions at each threshold
- **Primitives**: Atomic ontological units
- **Mechanisms**: Discovered causal patterns

```

├── docs/            # Governance and operational docs
```
