# Threshold Review Cycle

Threshold packages are reusable transition schemas, but they also carry revision norms and must be reviewed as the research program matures.

Minimum review cadence:

- Yearly framework review includes threshold definitions.
- Earlier review is triggered when a lane produces contradictory mechanism evidence or repeated collapse conditions.

Review checklist:

- Reconfirm the lower-order and higher-order regimes.
- Verify enabling primitives and activating modules still match the canon.
- Re-evaluate stabilization and collapse conditions.
- Record whether the package remains descriptive only or is ready to become a design pattern for simulation.
