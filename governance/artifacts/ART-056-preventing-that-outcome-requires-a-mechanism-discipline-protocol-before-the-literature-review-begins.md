# Preventing that outcome requires a mechanism discipline protocol before the literature review begins.

Source pair: `TH-056`

## Prompt

Proceed

## Response

If the research phase proceeds without guardrails, the mechanism registry will inevitably explode. Large synthesis projects routinely produce hundreds or thousands of loosely defined “mechanisms,” which then become impossible to organize or implement.


Preventing that outcome requires a mechanism discipline protocol before the literature review begins.


Below is the method that keeps the system coherent.



Mechanism Discipline Protocol


Preventing Registry Explosion


The protocol has five control layers.


candidate mechanism
→ normalization
→ primitive mapping
→ merge test
→ threshold placement
→ registry admission


Only mechanisms that pass all five layers enter the registry.



1. Mechanism Definition Standard


A mechanism must always be defined as:


a reproducible process
that transforms inputs into outputs
through identifiable steps


Minimum structure:


Mechanism Name
Inputs
Transformation process
Outputs
Relevant scale
Evidence source


If any of these are missing, the mechanism remains unadmitted.



2. Primitive Mapping Constraint


Every mechanism must map to the primitive canon.


Example:


Mechanism:


autocatalytic closure


Primitive mapping:


flow
network
feedback
constraint
stabilization


If a proposed mechanism introduces new primitives, it must be rejected or reformulated.


This prevents conceptual drift.



3. Mechanism Merge Test


Many “new mechanisms” are actually variants of existing ones.


Before admitting a mechanism, run the merge test:


Questions:


Is this simply a specific case of an existing mechanism?
Is the transformation identical but operating at a different scale?
Is it a combination of two existing mechanisms?


Example:


cultural imitation


may already be:


variation–selection + signal propagation


If yes, it should be classified under the existing mechanism rather than added as a new one.



4. Threshold Anchoring


Each mechanism must belong to a threshold transition.


Example thresholds:


matter → life
life → cognition
cognition → society
society → symbolic systems
symbolic systems → reflexive knowledge


If a mechanism cannot be placed within a threshold, it should not be admitted yet.


This keeps the registry tied to the evolutionary architecture.



5. Evidence Gate


Each mechanism must have at least one of the following:


empirical evidence
experimental evidence
simulation evidence
strong theoretical support


Mechanisms without evidence go into a speculative pool, not the registry.



Registry Admission Rule


A mechanism enters the official registry only if it satisfies:


definition standard
+
primitive mapping
+
merge test
+
threshold anchoring
+
evidence gate


Otherwise it remains in the candidate pool.



Expected Size of Registry


If this discipline is applied, the mechanism registry should stabilize around:


40–80 core mechanisms


Without discipline it easily grows beyond:


500–1000 mechanisms


which becomes unusable.



Example


Literature proposes:


kin selection


Analysis:


Primitive mapping:


signal
selection
network
memory


Merge test:


Kin selection is actually a variant of:


selection operating on relatedness networks


Registry decision:


merge into: evolutionary selection mechanisms


No new mechanism entry required.

Additional Control: Mechanism Families


Mechanisms should be grouped into families.


Example:


Chemical self-organization
Biological evolution
Cognitive inference
Social coordination
Symbolic transmission
Epistemic correction


Each family may contain variants, but only one core mechanism.



Research Workflow with Discipline


When reading literature:


read source
→ propose mechanism candidate
→ apply primitive mapping
→ run merge test
→ anchor to threshold
→ admit or reject


This keeps the registry coherent.



Strategic Outcome


With this protocol:


thousands of observations
→ dozens of mechanisms
→ a few threshold models
→ executable simulations


Without it:


thousands of observations
→ thousands of mechanisms
→ theoretical chaos



One More Crucial Insight


The mechanism registry should not grow indefinitely.


Its long-term purpose is:


mechanisms → module implementations → simulations


So the registry should eventually collapse into a smaller set of computational operators.


That is the real bridge between research and the universe engine.
