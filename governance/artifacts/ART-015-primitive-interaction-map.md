Primitive Interaction Map


Minimal Grammar of Universal Systems


This map takes the 60 Wave-1 seed primitives and organizes them into a small number of interaction grammars. The goal is to identify not just the primitives themselves, but the recurrent combinatory patterns by which they generate higher-order systems.


At this stage, the most useful move is to define:

The key claim is that most complex systems can be described as compositions of a relatively small number of recurring interactions.

III. Higher-Order System Formulas


Now the important step: how these interactions assemble into canonical system classes.


1. Dynamical System


Entity + State + State Space + Transition + Trajectory + Constraint
= Dynamical System


Examples:
physical motion, chemical reactions, population change, market fluctuation, narrative state progression.


2. Cybernetic System


System + Boundary + Input + Output + Feedback + Control + Goal/Constraint
= Cybernetic System


Examples:
thermostats, cells, organisms, institutions, AI agents.


3. Evolutionary System


Entity population + variation + selection + retention + environment
= Evolutionary System


Examples:
biological evolution, cultural evolution, algorithmic search, myth mutation.


4. Cognitive System


Observer + Observation + Model + Memory + Prediction + Feedback
= Cognitive System


Examples:
brains, animal perception, AI inference engines, distributed sensemaking.


5. Semiotic System


Symbol + Sign + Meaning + Encoding + Decoding + Interpretation
= Semiotic System


Examples:
language, ritual, visual culture, machine-readable representation.


6. Narrative System


State + Temporal Ordering + Agent + Goal + Constraint + Transformation
= Narrative System


Examples:
myth, literature, game progression, identity arcs.


7. Ecological System


Network + Flow + Constraint + Adaptation + Feedback + Environment
= Ecological System


Examples:
food webs, infrastructure webs, knowledge ecologies, platform ecosystems.


8. Civilizational System


Agents + Institutions + Infrastructure + Symbolic Order + Resource Flow + Governance
= Civilizational System


Examples:
states, empires, urban systems, techno-cultural complexes.
