9. Suggested execution cadence


To keep this from becoming a hoard instead of a system, the basic cadence should be:

Unit
Output
per source
1 $LANE_NOTE
per lane
1 $LANE_SYNTHESIS
per band
1 $BAND_MEMO
per reusable abstraction
1 $PRIMITIVE_EXTRACT
per unstable concept
1 $GLOSSARY_ENTRY

The correct rhythm is:


read → note → compare → synthesize → extract → govern terminology


Not:


read endlessly → accumulate highlights → lose the structure
