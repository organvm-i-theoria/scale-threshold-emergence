# The 12 Mechanism Families

Source pair: `TH-057`

## Prompt

Procedd

## Response

To keep the mechanism registry from fragmenting, mechanisms should be absorbed into a small number of high-level families. Each family represents a fundamental mode of process found across physics, biology, cognition, society, and symbolic systems. Nearly every mechanism discovered during research will be a specialization of one of these families.


Below is a 12-family structure that is broad enough to absorb most mechanisms but compact enough to keep the registry stable.



The 12 Mechanism Families


These are organized roughly along the emergence ladder from physical systems to reflexive knowledge systems.



1. State Transformation


Core function: change of system state.


Typical mechanisms:


phase transitions

chemical reactions

mutation

belief update

institutional reform


Primitive pattern:


state_t → transformation rule → state_t+1


This family is the most fundamental; everything else operates on top of it.



2. Constraint Enforcement


Core function: limiting possible state transitions.


Typical mechanisms:


conservation laws

regulatory rules

structural limits

institutional norms


Primitive pattern:


possible transitions
→ constraint filter
→ allowed transitions


Constraints shape what the system can become.



3. Flow and Throughput


Core function: movement of matter, energy, or information.


Typical mechanisms:


thermodynamic energy flow

metabolic throughput

communication signals

economic exchange


Primitive pattern:


source → pathway → sink


Without flow, systems stagnate.



4. Coupling and Interaction


Core function: linking separate processes.


Typical mechanisms:


predator–prey coupling

neuron interaction

market feedback

social influence


Primitive pattern:


system A state → modifies system B
system B state → modifies system A


This family produces network behavior.



5. Feedback Regulation


Core function: self-correcting loops.


Typical mechanisms:


homeostasis

hormonal regulation

thermostat control

market stabilization


Primitive pattern:


output → monitoring → corrective input


Two types dominate:


negative feedback (stabilization)

positive feedback (amplification)



6. Pattern Stabilization


Core function: persistent structures emerging from dynamic processes.


Typical mechanisms:


crystal formation

cellular organization

social roles

institutional structures


Primitive pattern:


repeated dynamics → stable configuration


Objects become temporary equilibria in motion.



7. Variation and Selection


Core function: adaptive change through differential survival.


Typical mechanisms:


natural selection

cultural evolution

technological competition

idea selection


Primitive pattern:


variation generation
→ environmental filtering
→ retention of successful variants


This family drives evolution.



8. Self-Organization


Core function: spontaneous order from local interactions.


Typical mechanisms:


autocatalytic networks

flocking behavior

market coordination

decentralized governance


Primitive pattern:


local rules → emergent global pattern


No central controller is required.



9. Representation and Modeling


Core function: systems forming internal models of the environment.


Typical mechanisms:


neural representations

predictive processing

scientific modeling

institutional forecasting


Primitive pattern:


signal input → internal representation → prediction


This is where cognition begins.



10. Communication and Sign Systems


Core function: structured transmission of meaning.


Typical mechanisms:


language

symbolic rituals

written records

digital communication


Primitive pattern:


signal → encoding → transmission → decoding


This family supports cultural evolution.



11. Replication and Propagation


Core function: copying structures across time or space.


Typical mechanisms:


genetic replication

meme transmission

software copying

institutional imitation


Primitive pattern:


pattern → copy → spread


Replication enables persistence across generations.



12. Reflexive Revision


Core function: systems modifying their own rules.


Typical mechanisms:


scientific revolutions

legal reform

meta-learning algorithms

philosophical critique


Primitive pattern:


system model → evaluation → rule revision


This family enables self-directed evolution.



Structural Role of the Families


The families form a layered stack.


state transformation
constraint enforcement
flow and throughput
coupling and interaction
feedback regulation
pattern stabilization
variation and selection
self-organization
representation and modeling
communication and sign systems
replication and propagation
reflexive revision


This stack roughly corresponds to the emergence chain:


physics
chemistry
biology
cognition
society
symbolic culture
science



Registry Discipline Rule


When a new mechanism appears in literature:


Identify the mechanism family first.

Determine if it is a variant of an existing mechanism.

Only create a new mechanism entry if it cannot be absorbed.


Example:


predictive processing
→ family: representation and modeling


kin selection
→ family: variation and selection



Expected Registry Shape


After a full research phase, the registry might look like:


12 families
≈ 40–80 core mechanisms
≈ 200–300 literature variants


But only the core mechanisms appear in the canonical registry.



Why This Structure Works


This structure mirrors recurring patterns across disciplines:


physics

biology

neuroscience

economics

anthropology

linguistics

philosophy of science


Many apparently different mechanisms are actually the same process appearing at different scales.



Strategic Result


With this family system in place:


literature review
→ mechanism candidate
→ family classification
→ merge test
→ registry update


The registry remains compact, navigable, and implementable.
