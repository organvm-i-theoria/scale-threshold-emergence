Threshold Package Library

The Transition Atlas identified the decisive interfaces in the stack.

Formally:


lower-order regime
+ enabling primitives
+ activating modules
+ threshold conditions
+ stabilization conditions
= higher-order regime


This is the most useful format for later theory, simulation, and architecture design because it isolates the irreducible crossing conditions.
