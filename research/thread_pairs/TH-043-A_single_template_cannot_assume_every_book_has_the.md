# TH-043 — A_single_template_cannot_assume_every_book_has_the

## Prompt

How does one template fit all the books? And while we're at it, if you're going to provide one, ensure it will digest and cover the whole book.

## Response

A single template cannot assume every book has the same structure, but it can be designed to capture the same analytical outputs regardless of the book’s style. The goal is not to force books into the same outline; the goal is to force the researcher’s extraction process into the same structure so the outputs remain comparable across sources.


Think of it as a mechanism extraction instrument, not a reading summary format.


The template therefore must cover five layers of digestion:


bibliographic context
argument structure
mechanism extraction
cross-domain mapping
research implications


Below is a full-book digestion template designed so that any academic or theoretical book can be processed through it and produce consistent outputs.

Key Principle


The template does not summarize books.

One refinement would make this even stronger: building a chapter-level micro-template that allows mechanism extraction while reading instead of after finishing the book. That reduces the time required to process long works significantly.
