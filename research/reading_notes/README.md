# Reading Notes Index

This directory contains structured notes from canonical sources in the research lanes.

## Structure

Each reading note follows the mechanism extraction template and includes:

- Source metadata (author, title, year, pages)
- Key concepts extracted
- Mechanisms identified
- Cross-references to other readings
- Notes and observations

## Usage

Create new reading notes using the template: `research/indexes/mechanism_extraction_template.md`

Naming convention: `{author_year_short_title}.md`

Example: `kauffman_1993_origins_of_order.md`
