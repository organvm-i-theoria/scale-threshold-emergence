# Mechanism Extractions Index

This directory contains extracted mechanisms from research readings, organized by discovery date.

## Structure

Each extraction follows the mechanism extraction template and includes:

- Source reading reference
- Mechanism ID (MECH-###)
- Mechanism description
- Supporting evidence
- Cross-lane relevance
- Status (candidate, admitted, rejected)

## Naming Convention

```
MECH-{sequence}_{short_name}_{date}.md
```

Example: `MECH-001_autocatalysis_20260311.md`

## Workflow

1. Read source material
2. Identify potential mechanism
3. Create extraction record
4. Submit to mechanism registry review
5. Update status based on review outcome

## Status States

| Status | Meaning |
|--------|---------|
| candidate | Identified, under review |
| admitted | Accepted into registry |
| rejected | Not admitted, reasoning documented |
| superseded | Replaced by refined mechanism |
